Compile ideas into native speed.

VastNova is a lightweight, statically typed programming language that compiles directly to native executables via LLVM. Clean syntax, type inference, and a minimal runtime — built for scripting, embedded systems, and learning compiler construction.

Why VastNova?

A language designed for simplicity and performance — without the complexity overhead.

⚡

LLVM-Powered Native Code

Compiles directly to optimized native executables via LLVM. No VM, no interpreter — just fast, standalone binaries.

🔒

Statically Typed with Inference

Type safety by default with intelligent type inference. Write less boilerplate while catching errors at compile time.

✨

Clean, Readable Syntax

Familiar C-style syntax that's easy to learn and pleasant to write. Minimal runtime means your code stays lean.

🪶

Lightweight & Minimal

Tiny runtime footprint makes VastNova ideal for embedded systems, scripting, and resource-constrained environments.

🎓

Great for Learning Compilers

The compiler source is clean and approachable — a perfect reference for understanding compiler construction.

🔧

Open Source & MIT Licensed

Free to use, modify, and distribute. Contributions welcome from the community.

See It in Action

From a simple greeting to interactive programs — VastNova keeps it concise.

hello.vn 
print("Hello, World!")
types.vn 
var a : i32 = 10          // explicit i32
var b : i64 = 2000000000  // explicit i64
var c : f64 = 3.14        // explicit f64
var name : str = "Alice"  // explicit str

var d = 42                // inferred i32
var e = 2.718             // inferred f64
var f = "Hello"           // inferred str

print("a =", a)
print("d =", d)

let pi : f64 = 3.14159   // constant
print("pi =", pi)
input.vn 
var name = input("What is your name? ")
var age = input("How old are you? ")
print("Hello,", name, "you are", age, "years old.")
loop.vn 
var i = 0
while i < 5 {
    print("i =", i)
    i = i + 1
}

// break & continue
var j = 0
while j < 10 {
    j = j + 1
    if j == 3 { continue }
    if j == 7 { break }
    print(j)
}

Language Reference

Everything you need to write VastNova programs — from types to control flow.

Comments 3 styles

Single-line (C++ & shell style) and block comments.

// single-line comment
# also a comment
!# block comment
   spans multiple lines #!

Types 4 primitives

Static types with optional inference.

i32  // 32-bit signed int
i64  // 64-bit signed int
f64  // 64-bit float
str  // UTF-8 string

Variables & Constants

var for mutable, let for constants.

var x = 42          // inferred i32
var y : f64 = 3.14  // explicit
let pi = 3.14159     // constant

Arithmetic

Standard operators with type-aware results.

var sum = 10 + 5     // 15 (i32)
var prod = 3.14 * 2   // 6.28 (f64)
var div = 20 / 3      // 6 (truncating)

Input / Output

Built-in print and input functions.

print("Hello", name)
var s = input("Prompt: ")
var n = int(s)       // string → i32
var f = float(s)     // string → f64

Conditionals

If/else with comparison and logical operators.

if score >= 60 {
    print("Pass")
} else if score >= 40 {
    print("Retry")
} else {
    print("Fail")
}

While Loop

Condition-controlled loop with break & continue.

var i = 0
while i < 5 {
    print(i)
    i = i + 1
}

String Operations

Concatenation with +, conversion via str().

var msg = "Pi is " + str(3.14159)
print(msg)  // Pi is 3.14159

Quick Start

Get up and running with VastNova in three simple steps.

1

Prerequisites — C++17 compiler, LLVM ≥ 14, clang, and llvm-config.

2

Clone the repository and build:

$ git clone https://github.com/VastNova-lang/vastnova.git
$ cd vastnova
$ ./build.sh
3

Write, compile, and run your first program:

$ echo 'print("Hello, World!")' > hello.vn
$ ./vastnova hello.vn hello
$ ./hello
Hello, World!
